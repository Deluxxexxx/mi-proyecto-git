"# Mi Proyecto" 

- Proyecto para devops

# Init

Se usa para inicializar el repositorio local.

# Add

Se usa para añadir archivos al staging, osea archivos que seran incluidos en el proximo commit.

# Commit

Guarda los cambios realizados en los archivos de manera local.

# Push

Mueve los cambios hechos de forma local al repositorio remoto.

# Status

Muestra los cambios realizados en los archivos.

# Diff

Muestra las diferencias entre dos archivos o repositorios.

# Log

Muestra el historial de cambios del repositorio de forma cronologica.

# Reset

Deshace cambios moviendo el repositorio hacia un commit anterior.
